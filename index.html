A little more context

I'm a final-year Computer Science student at KLS VDIT (VTU), Haliyal, finishing up in 2026, and I spent the first half of this year as a DevOps intern at JSpiders in Bengaluru. Most of my time goes into the parts of software that happen after the code is written — getting a build to trigger reliably, getting a container to start cleanly, getting a cluster to stay healthy under load.

Outside my internship I've shipped three infrastructure-heavy side projects on my own: a self-managed Kubernetes cluster provisioned entirely through Terraform and Ansible, a Jenkins pipeline with autoscaling for a Spring Boot app, and a live dashboard that streams pod logs and cluster alerts from whichever Kubernetes cluster you point it at. I like debugging real failures — CrashLoopBackOff, ImagePullBackOff, a node that just won't join — more than I like reading about them.
